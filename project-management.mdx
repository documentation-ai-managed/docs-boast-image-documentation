## Team Collaboration Features

Boast's collaboration tools ensure seamless teamwork across distributed teams and time zones.

| Feature | Description | Benefits |
|---------|-------------|----------|
| Real-time Editing | Multiple users can work simultaneously | Faster iteration cycles |
| Version Control | Track changes and revert if needed | Maintain design integrity |
| Comment Threads | Contextual discussions on specific elements | Clear communication |
| File Sharing | Secure sharing of assets and resources | Centralized access |

<Expandable title="Managing Remote Teams" default-open="false">
  For distributed teams, leverage Boast's asynchronous collaboration features. Set clear expectations for response times, use detailed comments, and schedule regular sync meetings to maintain alignment.
</Expandable>

<CodeGroup tabs="cURL,Bash">
  ````bash
curl -X POST https://api.boast.com/projects \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Website Redesign",
    "type": "web_design",
    "team": ["user1@example.com", "user2@example.com"],
    "deadline": "2024-03-01"
  }'
````
  ````bash
# Update project status
curl -X PATCH https://api.boast.com/projects/proj_123 \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"status": "in_review"}'
````
