## Release History

<Update label="2024-10-15" description="v2.1.0" tags={["feature", "improvement"]}>

## New Features

- Introduced advanced annotation tools with shape recognition for more precise feedback
- Added bulk feedback import from CSV files to streamline data migration
- Implemented smart notifications that prioritize urgent feedback based on project deadlines

## Improvements

- Enhanced mobile responsiveness for better access on tablets and smartphones
- Optimized image loading with progressive rendering for faster page loads
- Improved search functionality with filters for feedback status and reviewer

</Update>

<Update label="2024-09-20" description="v2.0.0" tags={["feature", "breaking"]}>

## New Features

- Launched real-time collaboration features allowing multiple users to provide feedback simultaneously
- Introduced project templates for common use cases like website redesigns and mobile apps
- Added integration with popular design tools including Figma and Sketch

## Breaking Changes

- Updated API endpoints for feedback collection to support new real-time features
- Modified user permission structure to accommodate granular access controls

</Update>

<Update label="2024-08-10" description="v1.5.0" tags={["feature", "bugfix"]}>

## New Features

- Implemented dark mode support for improved user experience in low-light environments
- Added export options for feedback reports in PDF and Excel formats
- Introduced team analytics dashboard for tracking feedback patterns and productivity

## Bug Fixes

- Fixed issue with image annotations not saving correctly in some browsers
- Resolved authentication timeout problems for long-running sessions
- Corrected display issues with feedback threads on high-resolution displays

</Update>
